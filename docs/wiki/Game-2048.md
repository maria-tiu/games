## Gameplay Overview

Slide tiles on a 4 × 4 grid to merge matching numbers. Each merge doubles the tile
value. Reach the **2048** tile to win — then keep going for an even higher score!

---

## Controls

| Key | Action |
|-----|--------|
| `←` `→` | Slide all tiles left / right |
| `↑` `↓` | Slide all tiles up / down |
| `W` `A` `S` `D` | Alternative move keys |
| Swipe | Touch-screen swipe to move tiles |

---

## Scoring

The score increases by the value of each merged tile.  
For example, merging two `64` tiles adds **128** points.

The **best score** is persisted in `localStorage` (`2048-best`) so it survives page
refreshes.

---

## Game States

| State | Condition |
|-------|-----------|
| **Playing** | Normal play |
| **Won** | A tile with value `2048` is created |
| **Game Over** | No empty cells remain and no adjacent tiles can merge |
| **Keep Going** | After winning the player can continue to aim for higher tiles |

## Technical Implementation

### Hook: `use2048Game` (`hooks/use2048Game.ts`)

Manages all game state. Exposes:

| Value / Function | Description |
|-----------------|-------------|
| `state` | Current `Game2048State` |
| `move(direction)` | Slide tiles in one of four directions |
| `newGame()` | Reset to a fresh board |
| `keepGoing()` | Dismiss the win overlay and continue playing |

### Game State

```typescript
interface Game2048State {
  board: (number | null)[][];  // 4 × 4 matrix; null = empty cell
  score: number;               // Current session score
  best: number;                // All-time best (from localStorage)
  gameOver: boolean;
  won: boolean;
  continueAfterWin: boolean;
}
```

### Board Representation

A 4 × 4 matrix of `number | null`. `null` represents an empty cell. Tile values are
always powers of 2 (2, 4, 8, … 2048, 4096, …).

### Move Logic (Board Rotation Technique)

All four directions are handled by reducing every move to a **"slide left"** operation:

1. **Rotate** the board so the target direction becomes "left":
   - `left` → no rotation
   - `right` → rotate 180°
   - `up` → rotate 90° clockwise
   - `down` → rotate 90° counter-clockwise
2. Apply `slideRowLeft` to every row.
3. **Rotate back** to the original orientation.

```typescript
// Slide a single row left, merging equal adjacent tiles
function slideRowLeft(row): [(number | null)[], scoreGained]
```

Rules for `slideRowLeft`:
- Filter out `null`s to get tiles in order.
- Scan left to right: if two consecutive tiles have the same value, merge them (add).
- A merged tile cannot merge again in the same move.
- Pad the right side with `null`s back to length 4.

### Tile Spawning

After every valid move, a new tile is placed in a random empty cell:
- **90%** chance of value `2`
- **10%** chance of value `4`

### Win / Game-Over Detection

```typescript
function hasWon(board): boolean   // any cell === 2048
function isGameOver(board): boolean
// ↳ no empty cells AND every direction produces no change
```

### Best Score Persistence

const BEST_KEY = '2048-best';

### Score Submission

When a game ends (game over) and the user is logged in, the score is automatically
submitted to `POST /api/scores/` with `game_id: "2048"`.
